# 미로 구출 게임 설계 — `maze.html`

날짜: 2026-05-30
대상: 새 독립 게임 파일 `/Users/eunhuismacbook/Desktop/hanigame/maze.html` + 허브 `index.html` 카드 추가
사용자: 한승한(6세), 영어 말하기 대회(2026-07-05) 준비 앱. 승한이는 미로를 좋아하고 꽤 잘함.

## 한 줄 요약

미로를 손가락으로 그려(자동 따라가기) 갇힌 영웅을 구출한다. 갈림길마다
영어 단어를 듣고 맞는 방향(그림 표지판)으로 가는 힌트를 받고, 도착하면
영어 문장 1개를 듣고 따라 말한다. 소방관 → 경찰관 → 의사 3판.

## 핵심 결정 (대표 확정)

- 영웅 구출 미로 + 갈림길 영어 힌트 + 도착 문장 따라말하기.
- 이동: **너그러운 자동 따라가기**(손가락 터치). 통로만 따라가고 벽 통과 못 함.
- **칸을 널찍하게**(셀 픽셀 크게) — 6세 손가락이 칸 안을 정밀히 따라 그리기 어려움.
- 단, **미로를 너무 단순화하지 말 것** — 갈림길·막다른 길 충분히. 승한이는 미로 잘함.
- **표지판은 충분히 크게**.

## 화면 구성

- 상단 바: `단계 N/3` + 구출할 영웅 아이콘/이름 + 🔊 힌트 다시듣기 버튼 + 🏠 허브 버튼.
- 본문: 미로 캔버스(가능한 크게, 화면 폭에 맞춤).
  - 시작 칸: 플레이어 표식(예 🤖 또는 발자국 시작점).
  - 목표 칸: 갇힌 영웅 아이콘(🚒/🚓/🚑 or 🧑‍🚒/👮/👨‍⚕️).
  - 손가락 따라 이어지는 **빛나는 코럴색 선**(브랜드 톤) = 지나온 길.
- 도착 화면: 구출 연출 🎉 + 영어 문장 카드(영문+한글) + 🔊 다시듣기 + ▶ 다음 판.

## 미로 생성

- 알고리즘: **재귀 백트래커(DFS) 완벽 미로** — 항상 풀림, 갈림길/막다른길 자연 발생.
- 그리드(칸 수) — 널찍한 셀과 복잡도 균형:
  - 1판 소방관: 9×9
  - 2판 경찰관: 11×11
  - 3판 의사: 13×13
- 셀 픽셀 크기: 캔버스 폭 / 칸수로 산출하되 **최소 한 변 44px 이상**(터치·가독성).
  화면이 작으면 칸수 유지 위해 캔버스를 세로로 키우고 스크롤 없이 보이게 폭 우선 맞춤.
- 통로 폭 = 셀 폭(벽은 셀 경계 선). 통로가 넉넉해 보이도록 벽 두께는 얇게(2~4px).
- 시작 = 좌상단 근처, 목표(영웅) = 우하단 근처. 시작→목표 유일 해답 경로 존재(완벽미로 성질).

## 이동 — 너그러운 자동 따라가기

상태: `player`(현재 칸 좌표 r,c), `trail`(지나온 칸 배열), `finger`(현재 터치 좌표 or null).

매 프레임:
1. `finger`가 없으면(손 뗌) 정지.
2. 손가락 픽셀좌표를 칸좌표로 환산, 플레이어와의 방향 계산.
3. 플레이어의 **인접 4칸 중 벽이 없고**(통로 연결) 손가락 방향에 가장 부합하는 칸으로 한 칸 이동.
   - 이동 속도: 칸당 짧은 보간(예 0.08s)로 부드럽게. 한 프레임에 한 칸씩 큐잉.
   - 손가락이 이미 지나온 칸(직전 칸) 쪽이면 **되돌아가기**(trail pop).
4. 새 칸이 목표면 도착 처리.

너그러움 포인트:
- 손가락이 벽/통로 밖을 가리켜도, 그 방향에 **열린 인접 칸**이 있으면 그 칸으로 진행.
  열린 칸이 없으면 제자리(막힘) — 답답하지 않게 시각 흔들림 없이 대기.
- 정밀히 선 안을 따라갈 필요 없음. "손가락 근처의 통로"를 영웅이 알아서 따라감.

입력: 캔버스에 `touchstart/touchmove/touchend`(+마우스 대응)로 `finger` 갱신. iPad 우선.

## 갈림길 영어 힌트 (그림 표지판)

- "갈림길 칸" = 진행 방향 기준 분기(2개 이상 열린 인접 칸이 있는 칸).
- 해답 경로 상의 갈림길에 도달하면, 분기 입구마다 **큰 그림 표지판**을 띄움
  (정답 방향 + 오답 방향 각각 다른 그림). 표지판 한 변 ≥ 셀의 0.7배, 최소 40px.
- TTS가 **정답 방향의 단어**를 말함(예 "fire truck!" → 🚒 표지판 쪽이 정답 힌트).
- 🔊 버튼으로 다시 듣기.
- 영어는 **도우미 힌트**: 틀린 길로 가도 안전(막다른 길 → 되돌아오면 됨). 미로 자체는 직접 풂.
- 표지판 그림 세트(작은 어휘): 영웅/탈것/도움 관련 이모지 풀에서 추출
  (🚒 fire truck, 🚓 police car, 🚑 ambulance, 🐶 dog, 🍎 apple, ⭐ star 등).
  정답 표지판 = 해답 경로, 오답 표지판 = 분기 오답 경로에 배치.

> 참고: 모든 갈림길에 표지판을 둘 필요는 없음(YAGNI). 해답 경로 분기에만 두어
> 힌트로 기능. 1차 구현은 해답 경로의 분기마다 표지판 1세트.

## 도착 — 영웅 구출 + 영어 문장

- 목표 칸 도달 → 구출 연출(영웅 아이콘 확대/반짝, 파티클, 효과음).
- 영어 문장 1개 TTS 재생 + 카드 표시(영문+한글), 🔊 다시듣기, ▶ 다음 판.
  speech.html `HEROES` 대사 재활용:
  - 소방관: "Firefighters are brave." (소방관은 용감해요) — color `#FF5722`
  - 경찰관: "Police officers are strong." (경찰관은 강해요) — color `#1565C0`
  - 의사:   "Doctors are kind." (의사는 친절해요) — color `#2E7D32`
- 3판 모두 구출 → 축하 화면(별·문구 "모든 영웅을 구했어요!").

## 음성(TTS)

- 브라우저 `speechSynthesis`로 영어 발화(en-US). 기존 게임들과 동일 방식.
- iOS 자동재생 제한 대비: 첫 사용자 터치 시 오디오/음성 unlock(기존 게임 패턴 참고).

## 코드 구조 (단일 파일 내 분리)

- `genMaze(n)` → 벽 정보 격자 반환(순수 함수, 테스트 가능).
- `solvePath(maze,start,goal)` → 해답 경로(표지판·힌트 배치용).
- 렌더: `drawMaze`, `drawTrail`, `drawSignposts`, `drawHero`.
- 입력: 터치 핸들러 → `finger`.
- 루프: `update`(이동)·`render`. requestAnimationFrame.
- 화면 전환: 미로 화면 / 도착 카드 / 축하 — 기존 게임처럼 div show/hide.
- 성능: 정적 미로(벽·격자)는 1회 오프스크린 렌더 후 매 프레임 drawImage(의사게임 cleanup 교훈 적용).

## 허브 연동

- `index.html`에 카드 추가: `href="maze.html"`, 이름 "🌀 미로 구출"(가칭),
  설명 "영어 듣고 길 찾아<br>영웅 구출!", NEW 배지. 기존 카드 마크업 패턴 따름.

## 검증 (헤드리스 Playwright)

- `genMaze` 결과가 완벽미로(모든 칸 연결, 사이클 없음) 단위 점검.
- 해답 경로를 따라 `finger`를 순차 이동(좌표 주입)시켜 영웅 도달 → 단계 증가 확인.
- 벽 방향으로 손가락 줘도 통과 못 함(제자리) 확인.
- 3판 클리어 → 축하 화면.
- 콘솔 에러 0.

## 범위 / YAGNI

- 점수·타이머 없음(미로는 탐험·구출 중심, 6세 부담↓).
- 표지판은 해답 경로 분기에만(전 갈림길 X).
- 미로 저장/이어하기 없음. 매판 새 생성.
- 다국어/난이도 설정 화면 없음(판=난이도 고정 3단계).

# 검토 반영 — 보강 사양 (v2, 2026-05-30 독립검토 2건 후)

디자인/UX·엔지니어링 독립 검토에서 나온 must-fix를 반영. 아래가 1차 구현의 확정 사양.

## A. 시작 안내(온보딩) 상태 — 필수

- 미로 진입 후 ~1.5초 입력 없으면: 시작 칸에서 **손가락 아이콘 펄스 애니메이션** +
  목표(영웅) 방향으로 점선 화살표 한 번. 음성+자막 "Drag to the hero! 영웅한테 데려가줘!".
- 첫 터치 시작되면 안내 사라짐. (6세가 첫 화면에서 '뭘 해야 하는지' 모르는 문제 차단)

## B. 이동 규칙 — 정밀화(결정적) + 리시(leash) + 갈림길 커밋

기존 "손가락 방향에 가장 부합하는 칸" 모호함 제거. 확정 규칙:

1. **리시(leash)**: 영웅은 손가락이 **현재 칸 또는 인접 칸 범위 안**에 있을 때만 다음 칸으로 이동.
   손가락이 멀리 있어도 통로를 자동 질주하지 않음(agency·갈림길 힌트 보존, 테스트 결정성 확보).
2. **다음 칸 선택**: 손가락 픽셀이 **실제로 들어간 인접 칸**으로만 이동. (방향 추정 X → 의도와 불일치 제거)
   - 손가락이 인접 통로 칸의 경계 안으로 들어오면 그 칸으로 한 칸 이동.
   - 동시에 두 칸 후보면(대각 모서리) **직전 진행축 우선 → 고정순서 상/우/하/좌**로 타이브레이크(결정적).
3. **갈림길 커밋**: 현재 칸이 분기(아래 D 정의)면 자동 진행 멈추고, 손가락이 한 통로 칸에
   확실히 들어올 때까지 대기. (틀린 통로 자동 진입 방지)
4. **너그러운 되돌리기**: 손가락이 지나온 trail 위 어느 칸에 오면 그 칸까지 trail을 고무줄처럼 되감음
   (직전 한 칸만 X). 막다른 길에선 영웅 살짝 '쿵' + 부드러운 소리로 "되돌아가" 신호.
5. 이동 보간 0.08s/칸, 단 리시 때문에 큐 길이는 1~2칸으로 제한(질주 없음).

## C. 영어를 '듣게 만드는' 장치 (게이트 아님, 보상형)

- 분기 도달 시 **선-교육**: 각 표지판에 그림+영어 단어 라벨 잠깐 표시 + 정답 단어 1회 자동 발화
  (듣고→그림 연결을 테스트 전에 가르침).
- 정답 표지판 통로로 가면 **작은 보상**(✨반짝 + 그 단어 다시 1회). 영어 루프에 이유 부여.
- **오답 표지판은 의미적으로 멀게**: 🚒 vs 🍎/⭐/🐶 (🚒 vs 🚓처럼 헷갈리는 쌍 금지).
  배포 풀에서 **해당 판 영웅 이모지 제외**(목표와 혼동 방지).
- 영어는 여전히 힌트(틀려도 안전). 단 위 보상으로 자연히 듣게 유도.

## D. 분기(fork) 정의 — 정확히

- 분기 칸 = **들어온 칸(직전 trail 칸)을 제외한 열린 인접 칸이 2개 이상**인 칸.
  (기존 "열린 인접 2개 이상"은 일직선 통로도 분기로 오인 → 수정)
- 3갈래 분기: 정답=다음 해답 칸, 나머지 열린 통로마다 서로 다른 오답 표지판 1개씩.
- 시작/목표 인접 분기: 표지판 배포 풀에서 영웅 이모지 제외(위 C).

## E. 누락 상태 보강

- **TTS 음성 로딩 게이트**: speech.html의 `voiceschanged`/`loadVoices` 패턴 재사용.
  음성 준비 전 발화 금지, 준비되면 큐된 힌트 발화. 첫 터치 때 빈 utterance로 speechSynthesis 프라임
  (iOS는 WebAudio unlock과 speechSynthesis unlock 별개).
- **3판 클리어 화면에 ▶ "다시 하기"**(1판부터 재생성). 막다른 정적 카드 금지.
- **판별 다시하기**: 도착 카드의 ▶는 다음 판; 마지막 판은 축하 화면으로.

## F. 미로 생성 — 시드 + 짧은 막다른 길 + 최소 분기

- `genMaze(n, seed)` **시드 인자 추가**(재현 가능 → Playwright 테스트·디버그).
- DFS 완벽미로는 긴 구불 통로·깊은 막다른 길 경향 → 6세 지루/답답.
  생성 후 **막다른 가지 길이 캡**(2~3칸 초과 막다른 길은 벽 하나 터 단축) 또는
  growing-tree 혼합으로 분기↑·막다른길 짧게.
- **해답 경로 분기 최소 3개 보장**(미달이면 시드 바꿔 재생성) → 표지판/영어 루프가 충분히 발동.
- 크기 유지: 9×9 / 11×11 / 13×13 (막다른 길 단축으로 좌절 없이 복잡도 유지).

## G. 반응형 + 고해상도(DPR)

- **타깃: iPad 우선**(앱 사용 환경). 셀 크기 = `floor(min(가용폭, 가용높이) / n)`.
  44px는 **목표값**(하드 플로어 아님) — 작은 폰에선 셀이 44 미만으로 줄되 스크롤 없이 전부 보이게.
- **DPR 대응**: `canvas.width = cssW*dpr; canvas.height = cssH*dpr; ctx.scale(dpr,dpr)`.
  오프스크린 미로 캐시도 DPR 반영(2~4px 얇은 벽 선명). 회전/리사이즈 시 캐시 재생성.

## H. 시각(브랜드)

- trail = **단색 코럴(글로우 없음)** + 위에 또렷한 영웅 토큰. 글로우/반짝은 **구출 순간에만**.
  (브랜드 DESIGN.md: 코럴 절제·그림자/글로우 지양, 현재 칸 가독성 유지)

## I. 테스트 훅(결정성)

- `window.__maze = { grid, solution, setFinger(x,y), tick() }` 노출(헤드리스 주입·프레임 스텝).
- 시드 고정 `genMaze(n, seed)`로 완벽미로 성질(전 칸 연결·사이클 없음) 단위 검증.
- 해답 경로 좌표를 리시 규칙에 맞춰 칸 단위로 순차 주입 → 도달·단계증가 검증.
- 벽 방향 주입 시 제자리(통과 X) 검증. 3판 클리어→축하. 콘솔 에러 0.

## 확정 안 한 선택(대표 판단 필요 없음 — 기본값 채택)

# v3 재설계 — 카드 선택형 (2026-05-30 대표 확정)

기존 v2는 "손가락 드래그로 갈림길 통로를 직접 골라 들어가고, 표지판은 힌트"였다.
대표 구상과 차이 발견: **갈림길에서 영어 단어를 듣고 그림 카드를 골라야 그 길이 열린다**
(영어 듣기·고르기가 게임 핵심 루프). 아래가 확정 사양. v2와 충돌 시 v3 우선.

## 한 줄 요약 (갱신)

손가락으로 영웅을 끌어 미로를 다닌다. **갈림길에 닿으면 멈추고**, 영어 단어를 듣고
화면 아래 **그림 카드 2~3장 중 맞는 것을 눌러야** 그 방향 통로가 열린다.
열린 통로로 손가락을 끌어 전진. 도착하면 영어 문장 따라 말하기. 소방관→경찰관→의사 3판.

## 핵심 결정 (v3)

- **카드↔길 = 그림 맞추기**: 각 갈래 입구에 그림 표지판(기존 유지) + 화면 아래 같은 그림 카드.
  음성이 정답 단어 발화("Fire truck!") → 표지판/카드 중 🚒를 매칭해 누름.
- **카드 게이트**: 갈림길에서는 카드를 누르기 전까지 **모든 갈래 통로가 잠김**(드래그해도 못 들어감).
  카드를 눌러야 그 카드에 대응하는 갈래만 열려 드래그 진입 가능. (영어 듣기·선택 강제)
- **오답 카드 = 그 길로 갔다 되돌아오기**(대표 선택): 오답 카드를 누르면 그 오답 갈래가 열림 →
  드래그해 들어가면 **막다른 길에서 살짝 '쿵'**(오답 효과음 + 화면 흔들림) → 되돌아오면
  갈림길에서 카드 다시 표시. 틀려도 안전·탐험. (하드 게이트 아님)
- **오답 갈래는 짧게**: 오답 카드가 가리키는 갈래는 막다른 길 2~3칸 내로 단축(v2 F의 막다른 캡 유지)
  → 금방 되돌아옴. 좌절 방지.
- 이동 locomotion = **손가락 드래그 유지**(통로 자동 따라가기, v2 B 규칙 그대로). 카드는 갈림길 결정에만.

## 갈림길 인터랙션 흐름 (v3 확정)

1. 영웅이 분기 칸(v2 D 정의) 도달 → 자동 정지(기존 갈림길 커밋).
2. 각 갈래 입구에 그림 표지판 표시(기존 `G.signs`). 정답 갈래 = 영웅 이모지(예 🚒),
   오답 갈래 = 의미적으로 먼 distractor(🍎/⭐/🐶, 영웅 이모지 제외 — v2 C/D).
3. 음성이 **정답 단어 1회 자동 발화** + 🔊로 재청취(기존 동작 유지).
4. **화면 하단 카드 트레이**에 갈래 수만큼 그림 카드(표지판과 동일 이모지·셔플 순서) 표시. 카드 한 변 ≥ 64px.
5. 카드 탭:
   - **정답 카드** → 딩동 효과음 + ✨반짝 + 정답 단어 1회 재발화 + 정답 갈래 통로 **열림(unlock)**.
     카드 트레이 사라짐. 손가락으로 그 갈래에 드래그 진입.
   - **오답 카드** → 오답 갈래 **열림** + (선택 즉시 흔들림 없음, 진입 후 막다른 도달 시 처리).
     손가락으로 진입 가능. 막다른 끝 도달 시 **삐 효과음 + 화면 흔들림(짧게)**.
     되돌아와 분기 칸 재진입 시 카드 트레이 재표시(잠금 복구).
6. **잠금 규칙**: `activeFork` 활성 중 + 아직 카드 미선택이면, `tickMove`에서 분기 칸의
   **모든 갈래 진입을 차단**(되돌리기=직전 trail 칸으로 후퇴는 허용). 카드 선택으로 `unlockedBranch` 설정 후
   그 갈래만 진입 허용. 분기 칸을 떠나면(전후진) `signs/activeFork/unlockedBranch` 해제(기존 `afterMove`).

## 소리·진동 (v3)

- **진동 API 미지원**: iPad/iPhone Safari는 `navigator.vibrate` 미지원 → 진동 안 함.
  대체로 **화면 흔들림(canvas/컨테이너 짧은 shake 애니메이션)** + 효과음.
- 정답 = 딩동(상승 톤), 오답 = 삐(하강/버저 톤). WebAudio Oscillator로 합성(에셋 파일 불필요),
  기존 오디오 unlock 패턴(`_unlockAudio`)에 묶어 첫 터치 후 활성.
- (안드로이드 폰에서만 `navigator.vibrate` 있으면 짧게 추가 — 있으면 쓰고 없으면 무시, graceful.)

## 화면 구성 변경 (v3)

- 기존 상단 바·미로 캔버스·도착 카드·축하 유지.
- **추가: 카드 트레이** — 미로 캔버스 아래 고정 영역. 분기 활성 시만 표시, 평소 숨김.
  카드 = 큰 그림(이모지) + 작은 영어 라벨. 탭 타깃 ≥ 64px. iPad 가로폭에 2~3장 가운데 정렬.

## 코드 변경 범위 (maze.html 단일 파일)

- `enterCellFork()`: 기존대로 `G.signs`/`activeFork` 생성 + **카드 트레이 렌더 호출**, `unlockedBranch=null`.
- `tickMove()`: 분기 칸에서 `activeFork && unlockedBranch==null`이면 **모든 전진 차단**(되돌리기만 허용).
  `unlockedBranch` 설정되면 그 칸만 `stepTo` 허용.
- **신규 `chooseCard(item)`**: 카드 탭 핸들러. 정답이면 딩동+반짝+`unlockedBranch=정답갈래`+트레이 숨김.
  오답이면 `unlockedBranch=오답갈래`+트레이 숨김(막다른 도달 처리는 이동 중).
- **신규 `bumpDeadEnd()`**: 오답 갈래 막다른 끝 도달 감지 → 삐+화면 shake.
- `afterMove()`: 분기 떠날 때 `unlockedBranch` 포함 해제 + 카드 트레이 숨김.
- **신규 효과음**: `beepGood()`, `beepBad()` (WebAudio Oscillator). `_unlockAudio`에 AudioContext resume 추가.
- **신규 shake**: 캔버스 컨테이너에 CSS keyframe `shake` 클래스 토글.
- 오답 갈래 길이 단축: `buildLevel`에서 분기 오답 갈래의 막다른 깊이 2~3칸 캡(이미 있으면 유지/확인).

## 검증 (v3 추가)

- 분기 도달 시 카드 미선택 상태에서 **모든 갈래 드래그 차단** 확인(제자리).
- 정답 카드 탭 → 정답 갈래만 열리고 진입 가능 확인.
- 오답 카드 탭 → 오답 갈래 진입 → 막다른 도달 시 shake/효과음 1회 → 되돌아와 카드 재표시.
- 도착·3판 클리어·축하 기존 동작 회귀 없음. 콘솔 에러 0.
- 테스트 훅에 `window.__maze.chooseCard(idx)` 노출(헤드리스 카드 선택 주입).

## YAGNI (v3)

- 카드 정답까지 시도 횟수 제한·점수 없음(탐험 중심).
- 카드 애니메이션 화려하게 X(탭 즉시 반응 + 반짝만).
- 오답 길은 짧은 막다른 1종만(중첩 분기 X) — 되돌아오기 단순화.
